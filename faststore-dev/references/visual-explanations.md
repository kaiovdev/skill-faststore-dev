# Imagens explicativas

Leia esta referência quando o usuário pedir uma imagem para entender a interface, os componentes ou o fluxo de uma loja FastStore. Entregue o visual solicitado e uma legenda breve que ajude a interpretá-lo.

1. Antes de desenhar, analise o projeto do usuário no escopo pedido. Localize a seção ou página, os componentes renderizados, sua composição e seus consumidores; siga imports, props, hooks, estado, CMS e integrações até entender as conexões relevantes. Use os nomes e as relações encontrados nesse código, sem presumir a arquitetura de outra loja. Diferencie relações confirmadas de hipóteses: uma captura mostra a aparência, mas não comprova sozinha a composição React nem o fluxo de dados.
2. Para explicar uma interface existente, anote a captura ou imagem fornecida: preserve o layout, posicione rótulos legíveis e ligue cada rótulo ao elemento correto com linhas discretas. Represente componentes sem elemento visível em um diagrama separado, se forem relevantes. Para editar uma imagem bitmap, use a ferramenta de edição de imagem disponível.
3. Para explicar composição ou funcionamento, desenhe um diagrama com blocos e setas direcionais. Mostre a ordem de interação e os pontos de entrada, transformações, dados e resultados que importam para a pergunta. Use Mermaid ou SVG quando a precisão e a manutenção do diagrama forem úteis; produza uma imagem renderizada quando o usuário pedir uma imagem ou arquivo visual.
4. Confira se textos, conexões e direção das setas correspondem ao código. Mantenha contraste, tamanho de fonte e espaçamento suficientes para leitura. Evite cruzamentos desnecessários e detalhes que não ajudam a explicar o recorte pedido.
5. Cite os arquivos que sustentam os rótulos e o fluxo na resposta. Se não for possível confirmar uma relação pelo código disponível, sinalize a incerteza no texto ou no visual. Salve a imagem no projeto somente quando ela fizer parte da entrega solicitada; caso contrário, mostre-a na resposta.
